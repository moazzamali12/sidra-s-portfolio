# Sidra Tul Muntaha Ghouri — Portfolio Website

A personal portfolio website built for **Sidra Tul Muntaha Ghouri**, an Electrical Design Engineer with 5+ years of industrial experience in switchgear panel design, solar systems, and electrical estimation. The site showcases her projects, work experience, technical skills, and certifications to potential clients and employers.

**Live Site:** [moazzamali12.github.io/sidra-s-portfolio](https://moazzamali12.github.io/sidra-s-portfolio/)

---

## About This Project

Designed and developed as a personal portfolio piece. Built as a favor for a friend (Sidra) and doubling as a project in my own frontend development portfolio.

## Features

- **Hero Section** — Introduction with profile photo and quick call-to-action to view projects
- **About** — Summary of experience, specialization, and key stats (years of experience, projects delivered, clients served)
- **Skills** — Categorized display of tools and technologies (EPLAN Electric P8, EPLAN ProPanel, AutoCAD, CorelDRAW, SketchUp, MS Visio)
- **Projects** — Featured project cards with **flip-on-hover** animation revealing challenge, role, and outcome for each project
- **Experience** — Career timeline across multiple companies with detailed responsibilities
- **Certifications** — Flex display of professional certifications
- **Contact** — Contact form, downloadable resume (PDF), and direct links (WhatsApp, LinkedIn, email)
- **Fully responsive** — Built mobile-first and tested across breakpoints for phone and desktop
- **Hover animations** — Interactive hover states on cards, buttons, and links throughout

## Tech Stack

- HTML5 (semantic markup)
- CSS3 (Flexbox, Grid, responsive/mobile-first design, animations/transitions)
- Vanilla JavaScript

No frameworks or libraries — built from scratch to reinforce core web fundamentals.

## Running Locally

1. Clone the repository:
   ```
   git clone https://github.com/moazzamali12/sidra-s-portfolio.git
   ```
2. Open `index.html` directly in a browser, or serve it with a local dev server (e.g. VS Code Live Server extension) for the best experience.
